# خادم الإشعارات (Cloud Run)

خادم صغير يرسل إشعارات الجوال للطلاب عبر Firebase Cloud Messaging. يبدأ في أقل من ثانية ولا يحتاج ذاكرة كبيرة.

| الإعداد | القيمة |
|---|---|
| مصدر البناء | هذا المستودع، فرع `main`، ملف `/notify-service/Dockerfile` |
| فلتر الملفات في المشغّل | `notify-service/**` |
| المنطقة | `europe-west1` |
| الدخول | السماح بالوصول العام (الخادم يتحقق بنفسه أن المرسل معلم) |
| الفوترة | حسب الطلب (Request-based) |
| الذاكرة / المعالج | 512 MiB / 1 |
| عدد النسخ | الأدنى 0، الأقصى 1 |
| متغيرات البيئة | `FIREBASE_PROJECT=quran-c16c8` و `ALLOWED_ORIGINS=https://m3naji-droid.github.io` |

ثم في `js/firebase-config.js`:
- `PUSH.vapidKey`: من Firebase ← إعدادات المشروع ← Cloud Messaging ← Web Push certificates ← Generate key pair.
- `PUSH.url`: رابط هذه الخدمة.

## كيف يعمل
1. ينشئ المعلم واجباً، فيحفظ الموقع تنبيهاً في `notifs/{id}` (يظهر فوراً في جرس الطالب).
2. يطلب الموقع `POST /send {notif}` مع رمز دخول المعلم.
3. يقرأ الخادم التنبيه من قاعدة البيانات، ويرسله إلى أجهزة طلاب الصف في `pushTokens`، ويحذف رموز الأجهزة غير الصالحة.

## المؤقت (الإعلانات المجدولة وتذكيرات الواجبات)
1. في خدمة `fateh-notify` أضف متغير البيئة `CRON_SECRET` بقيمة سرية طويلة.
2. في Cloud Scheduler أنشئ مهمة:
   - Frequency: `*/10 * * * *` · Timezone: `Asia/Riyadh`
   - Target: HTTP · URL: `<رابط الخدمة>/cron` · Method: POST
   - Header: `X-Cron-Secret: <القيمة نفسها>`
3. تظهر حالة المؤقت في لوحة المعلم ← الإعلانات ← «تذكير الواجبات».

## تحليل التجويد على الخادم (لا يحتاج فتح صفحة المعلم)
حين يرسل الطالب واجباً لم يكتمل تحليل تجويده على جهازه، يُضاف إلى `aiq/{رقم الطالب}__{رقم التسليم}`
ويطلب الموقع `POST /ai`، فيأخذ هذا الخادم التسجيل من قاعدة البيانات ويرسله إلى خادم التحليل ويحفظ النتيجة
ويُشعر الطالب. وما فاته (انقطاع أو ازدحام) يلتقطه `/cron` كل ١٠ دقائق، بثلاث محاولات لكل تسليم.

الإعداد مرة واحدة:
1. اختر قيمة سرية طويلة (٣٢ حرفاً فأكثر).
2. خدمة التحليل (`fateh-quran-v2`) ← Edit & deploy new revision ← Variables: `INTERNAL_SECRET=<القيمة>`.
3. هذه الخدمة (`fateh-notify`) ← Edit & deploy new revision:
   - Variables: `AI_SECRET=<القيمة نفسها>` (ورابط خادم التحليل في `TAJWEED_URL` إن تغيّر).
   - Request timeout: `600` ثانية.
4. Firebase ← Firestore ← Rules: انشر محتوى `firestore.rules` من المستودع (فيه قاعدة `aiq`).

إن لم تُضبط `AI_SECRET` يبقى كل شيء كما كان: يحلّل جهاز المعلم ما فات بعد ١٥ دقيقة.
